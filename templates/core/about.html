About this system

This web app supports Kepler College Kigali student guild elections with secure voter verification, role-based access, and transparent aggregated results.

Students
  • Sign up using Email + Student ID
  • Email verification required
  • Vote once per position per election
  • View aggregated results only
Admins
  • Create elections, positions, candidates, campaigns
  • Block/unblock students from voting
  • View votes and generate reports
  • Enable/disable live results
